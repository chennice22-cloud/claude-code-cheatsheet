Claude Code 指令速查表

官方文档整理 · 2026年5月 · 适用于 v2.1.x
启动 / CLI 参数
claude在当前目录启动交互式会话
claude "任务描述"一次性执行任务后退出
claude -c继续上一个会话
claude -r <session-id>恢复指定会话
claude --model opus指定模型（opus / sonnet / haiku）
claude --print "任务"非交互式，输出结果到 stdout
claude --verbose显示每次工具调用的详情
claude --no-confirm跳过权限确认（CI 环境用）
claude --permission-mode plan只读计划模式，不执行操作
claude --add-dir ../path允许访问其他目录
会话管理指令
/clear清空对话历史，重新开始
/compact压缩上下文，释放 context
/context查看当前 context 用量分布
/rewind回滚到之前的检查点
/resume重新打开上一个会话
/btw快速插话不占 context
/cost查看本次会话 token 用量
/usage查看计划额度和速率限制
/export导出对话内容到文件
/copy复制最后一条回复
/diff查看未提交的变更和 diff
/plan进入只读计划模式
配置 / 权限 / 模型
/config打开设置（主题、默认值等）
/permissions查看/修改工具权限
/memory查看/编辑 CLAUDE.md 文件
/model opus切换到 Opus 4.7
/model sonnet切换到 Sonnet 4.6
/model haiku切换到 Haiku 4.5
/effort xhigh最高推理强度（Opus 专用）
/add-dir扩展本次会话的文件访问
/status账户、模型、目录、版本信息
扩展 / 工具生态
/mcp管理 MCP 服务器连接
/agents查看/创建子 Agent
/hooks查看 hook 事件配置
/skills列出本次会话可用的 skill
/simplify检查并优化近期修改的代码
/init分析代码库，生成 CLAUDE.md
认证 / 系统
/login登录 / 切换账户
/logout登出当前账户
/doctor诊断安装和环境问题
/help列出所有可用指令
/feedback向 Anthropic 反馈问题
/exit退出 CLI
键盘快捷键
Shift + Tab切换权限模式：默认 → 自动接受编辑 → 只读计划
Esc中断当前回复，立即重新输入
Esc Esc打开回滚菜单，恢复到检查点
Ctrl + C取消当前输入，或空行退出
Ctrl + R反向搜索历史 prompt
Ctrl + O展开完整 transcript 视图
↑ / ↓浏览历史 prompt 记录
@ + 路径在 prompt 中直接引用文件
/打开指令菜单
?显示当前环境的快捷键列表
实用环境变量
CLAUDE_CODE_NO_FLICKER=1平滑输出，不闪烁，支持鼠标滚动
ANTHROPIC_API_KEY设置 API Key（接第三方 API 时用）
ANTHROPIC_BASE_URL替换 API 地址（接 DeepSeek 等用）
claude auth status检查当前认证状态
